# Vendored veRL Snapshot

This directory contains the veRL snapshot used by CoEvoKG, including local
synchronization fixes required by the training launcher. It is kept in-tree so
that the release is reproducible.

Install it from the repository root with:

```bash
pip install -e ./verl
```

The original veRL project is released under Apache License 2.0. See `LICENSE`
and `Notice.txt` in this directory.
