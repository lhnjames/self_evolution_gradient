# ALFWorld 候选动作长期价值 × project300_last4 输出变化

价值定义：在记录状态强制执行一个候选动作，随后由 ALFWorld 官方 expert 恢复；
在总计 50 步预算内成功记为 1，同时报告 `0.95^(恢复步数-1)` 的折扣成功值。
该实验测量的是 expert-recovery 条件价值，不等同于 Base/SEED 自身 rollout 价值。

## valid_seen

- 444 个状态、33 个独立 game trial、12680 个候选动作。
- 候选动作在预算内的总体恢复成功率：94.09%。
- 有二元成功差异的状态：141；有折扣价值差异的状态：432。
- expert 动作 / Base top-1 / project300_last4 top-1 为最高价值动作的比例：40.77% / 31.31% / 44.14%。
- 80% 实用门槛：未通过（差值 -35.86 点）。
- project300_last4 概率加权折扣价值变化均值：+0.026225。
- Base / project300_last4 概率加权折扣价值：0.595442 / 0.621667；相对提升 4.40%（30% 硬门槛：未通过）。
- 最高价值动作命中率相对提升：41.01%。
- episode-cluster 95% CI：[+0.005336, +0.045171]。
- project300_last4 Δlogit 与动作价值的状态内 Spearman 均值：+0.268208。
