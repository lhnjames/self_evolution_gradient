## 解释边界

均值方向是共同成分的科学探针，不是最终算法。五个 verb cluster 的区间只能作为跨动作类型复现证据；不能把同一 verb 内的多对状态当成完全独立样本。只有在均值方向优于单源、且梯度几何能预测真实交叉写回时，才应继续顺序累积实验。
