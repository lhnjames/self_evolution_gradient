# 相似技能梯度自净化：方法与强验证方案

日期：2026-09-04

## 1. 核心问题

本阶段只研究一个问题：

> 当一个正在执行的 skill 失败后，由该失败状态的长期价值产生的参数梯度，能否被当作一种可检索、
> 可组合的经验，自动修复未参与反向传播的相似 skills，并在连续失败中形成稳定的自进化闭环？

现有结果已经否定三个过强假设，并直接限定了方法形态：

| 假设 | 实验结论 | 方法约束 |
|---|---|---|
| H6：单状态梯度只修复自身 | 否；同动作独立留出也改善 | 失败梯度可作为跨状态经验候选 |
| H8：单状态梯度足以代表经验 | 否；12 源共同方向显著更强 | 参数提交前必须积累多条独立证据 |
| H10：有用梯度可无限直接累积 | 否；同类收益放大时出现跨动作干扰 | 必须做技能隔离、冲突保护和回滚 |

因此，不能采用“失败一次就把原始梯度永久加进统一模型”的方案。本文提出：

> **SCGP（Skill-Conditioned Gradient Purification，技能条件梯度净化）**：失败首先形成技能条件梯度
> 记忆；只有多条独立失败经验形成稳定共同方向后，才进入影子写回。不同 skill 的更新默认隔离，
> 只有通过跨技能保护集验证的方向才能合并进共享参数。

## 2. 自净化闭环

```text
skill 执行失败
    ↓
环境干预得到候选动作长期价值 Vγ(s,a)
    ↓
计算失败经验梯度 g_s = ∇θ[-E_pθ(a|s)Vγ(s,a)]
    ↓
按 skill id / 状态阶段检索历史梯度，并用真实 gradient cosine 判断兼容性
    ↓
多经验共同方向净化：去除低一致性梯度，聚合保留方向
    ↓
生成 skill-conditional 参数 delta（或等价输出残差）
    ↓
在同 skill 独立留出、其他 skill 保护集和 unseen 状态上做影子验证
    ↓
达到 30% 门槛且无明显伤害：提交；否则回滚并仅保留为未晋升经验
    ↓
后续相似 skill 再失败时继续补充证据、重算共同方向
```

闭环中“净化”有两个含义：

1. **经验内净化**：剔除与同 skill 其他经验几何不一致的单状态梯度，避免单次失败噪声进入参数；
2. **经验间净化**：不同 skills 默认使用独立 delta，避免 `open` 的更新永久破坏 `go/close/take`。

## 3. 梯度经验表示

对于失败状态 `s` 的候选动作集合 `A(s)`，定义：

```text
L_s(θ) = - Σ_a pθ(a|s) Vγ(s,a)
g_s    = ∇θ L_s(θ)
```

当前只编辑最后四层或最后一层 MLP；本轮正式强实验使用最后四层 FP32 梯度。梯度记忆保存：

- skill 标识、任务类型、状态阶段、目标对象和前置条件；
- 梯度方向或其低维签名；
- 失败前候选分布和环境长期价值；
- 与同 skill 经验的 cosine；
- 影子写回后的同类收益、跨类伤害和是否晋升。

线上检索时，语义标签只用于缩小候选集合，是否兼容最终由梯度几何决定。现有 2,640 个定向写回对
已经显示，gradient cosine 与真实交叉迁移的 Spearman 为 `0.851–0.888`；最低 cosine 四分位
正迁移率为 0%，最高两个四分位为 100%。

## 4. 多经验共同方向

同一 skill 的 `K` 条独立失败经验记为 `g_1,...,g_K`。基础对照为单位梯度均值：

```text
d_mean = (1/K) Σ_i g_i / ||g_i||
```

本轮同时检验一个不读取留出测试结果的 cosine 硬净化候选。它仅根据源经验内部的一致性计算：

```text
c_i = median_{j≠i} cos(g_i,g_j)
```

保留 `c_i` 最高的三分之二，按相对一致性加权：

```text
w_i ≥ 0,  Σ_i w_i = 1
d_purified = Σ_i w_i g_i / ||g_i||
```

这个候选比“只保留与历史累计方向正 cosine 的梯度”更严格，但正式结果表明它仍不如保留全部
12 条独立经验的单位梯度均值。因此最终 SCGP 不采用硬删样本：cosine 用于相似经验检索和冲突
诊断，净化由独立留出晋升、技能条件隔离与回滚完成。

## 5. 冲突处理：先隔离，再合并

H10 的直接答案不是设计更复杂的全局求和，而是改变参数组织方式。

### 5.1 默认形态：技能条件 delta bank

每个 skill 保留独立参数增量 `Δθ_k`。当智能体明确正在执行 skill `k` 时，只激活该增量：

```text
θ(s) = θ_base + Δθ_route(s)
```

这允许一个 `open` 失败经验修复其他 `open` 状态，同时不在 `move` 状态激活。它仍然是对真实模型
参数的数字修改，只是把永久、无条件合并改为条件激活；等价实现可以是稀疏参数 delta、adapter，
或候选动作 logit residual。

### 5.2 晋升形态：共享参数合并

只有当某个方向同时满足以下条件时，才允许写入共享基础参数：

```text
同 skill 留出价值显著提高
其他 skill 保护集平均不下降
top-value harm ≤ 2%
valid_unseen 不下降
多写入顺序结果一致
```

否则该方向继续保留在条件 bank 中。也就是说，条件 delta 是默认安全层，共享参数是经过验证后的
长期巩固层。

## 6. 路由与信息泄漏边界

“相似 skill”必须在应用梯度前确定，不能根据写回结果事后分组。本项目同时报告两个口径：

1. **已知 skill 路由（机制上界）**：在技能式 agent 中，当前正在执行的 skill id 本来就是已知的。
   ALFWorld 离线实验用记录的 action skill 模拟这个条件。该结果回答“如果 skill 路由正确，梯度
   经验能否迁移”，不能直接宣称是端到端可部署结果。
2. **Base 预测 skill 路由（部署下界）**：只用 Base 当前第一选择动作的 verb 选择 delta，不读取
   expert action 或环境价值。该结果回答在没有 oracle skill id 时能保留多少收益。

若机制上界未达到 30%，说明梯度经验本身不足，暂停路线；若上界达到而部署下界失败，瓶颈是
skill router，应单独研究状态阶段识别，而不是把失败归因于梯度表示。

## 7. H6/H8/H10 正式验证

### 7.1 H6：一个失败梯度能否迁移到相似 skill

只选 Base top action 不是最高折扣价值动作的真实失败状态。当前可满足独立样本要求的 skill 为：

| skill | seen 失败状态 | 独立失败 episode | 本轮源/留出 |
|---|---:|---:|---:|
| go | 182 | 33 | 12 / 6 |
| open | 56 | 18 | 12 / 6 |
| close | 55 | 18 | 12 / 6 |

`take/move` 只有 4/1 个独立失败 episode，本轮不混入正式结论。每个单失败梯度都以相同 300×
参数 L2 写回，测量：

- 产生梯度的源状态；
- 未参与反传的同 skill 失败状态；
- 同任务不同 skill；
- 不同任务不同 skill。

H6 成立要求：单失败梯度在独立同 skill 留出上的平均长期价值为正，并显著强于两类异 skill 对照。
30% 是实用门槛，不用“统计显著但极小”替代。

### 7.2 H8：多失败共同方向是否优于单失败

等参数 L2 比较三种方法：

- `single12_average`：12 个失败梯度分别写回后的平均效果；
- `mean12`：12 个单位梯度直接平均；
- `purified12`：剔除一致性最低三分之一后的 cosine 加权共同方向。

使用 4 个预注册采样种子，共 `3 skills × 4 seeds × 12 = 144` 个单失败强写回，并额外执行
24 个多源强写回。H8 的主要统计单位是 `seed × skill`，不是把同 episode 内状态当作独立样本。

### 7.3 H10：隔离式累积能否避免跨技能污染

比较：

- 全部 delta 直接合并到一个模型；
- 历史累计方向正 cosine 过滤；
- 历史累计方向投影；
- SCGP 技能条件 delta bank；
- SCGP 通过保护集后再合并。

前 3 个对照已有 300× 数据；本轮新增后 2 个。必须分别报告已知 skill 路由与 Base 预测路由，
并在完全相同的 971 状态、FP32、prompt、tokenizer、候选动作和环境价值上横向比较 Base 与 SEED。

## 8. 30% 硬门槛与提交规则

不再以 `1e-4` 量级变化作为成功。候选方法必须逐级过门：

| 层级 | 成功条件 |
|---|---|
| 局部机制 | 同 skill 失败留出的概率加权长期价值相对 Base 提升至少 30% |
| 决策边界 | 在 Base 失败留出上至少救回 30% 状态，top-value harm 不超过 2% |
| 泛化 | valid_unseen 同口径提升至少 30%，且异 skill 保护集不下降 |
| 智能体能力 | 固定完整 episode 集合成功率相对 Base 提升至少 30%，多随机种子复现 |

如果只在 seen top-value 命中率超过 30%，但概率加权价值或 unseen 不到 30%，结论只能是“强分布内
决策编辑”，不能称为技能自进化。当前 300× 全局直接写回正属于这种情况：seen top-value 命中率
相对提高约 40%，但 seen 概率价值只提高约 4.5%，unseen 只有 `+1.12%/−0.04%`。

## 9. 停止条件与后续分支

优先级严格如下：

1. 先看 H6：300× 单失败梯度是否在独立同 skill 失败状态上有稳定大迁移；
2. 再看 H8：12 源净化方向能否把迁移推过 30%，并优于单源和普通均值；
3. 只有 H8 通过，才做 H10 的 971 状态条件路由和完整 episode；
4. 若已知 skill 路由上界仍未过 30%，停止扩大剂量，判定“当前价值梯度不足以替代技能训练”；
5. 若上界通过但 Base 路由失败，转向学习无标签 skill router；
6. 若离线 unseen 通过但完整 episode 失败，转向修正长期价值估计与闭环分布偏移。

这一停止规则保证方向确实能被否证：不会因为存在微小正数而无限继续，也不会把 oracle 路由、
seen 结果或离散动作翻转包装成端到端能力提升。

## 11. 300× H6/H8 实际结果

四个预注册采样种子全部完成。每个种子对 `go/open/close` 各使用 12 个独立 Base 失败 episode
形成梯度库，并在另外 6 个独立失败 episode 上验证。总计：

- 144 次单失败 300× 写回；
- 12 次普通 12 源共同方向写回；
- 12 次 cosine 硬净化方向写回；
- 168 次强参数写回、5,040 个写回后状态响应。

| 方法 | 同 skill 留出 ΔV | 概率价值相对提升 | 正迁移率 | 失败 top 救回 | 同 skill top harm |
|---|---:|---:|---:|---:|---:|
| 单失败梯度平均效果 | +0.059774 | +11.11% | 81.9% | +12.27 点 | 2.1% |
| 12 源单位梯度均值 | **+0.097772** | **+18.17%** | **98.6%** | **+15.28 点** | **0.0%** |
| cosine 硬净化 12 源 | +0.085545 | +15.89% | 90.3% | +11.11 点 | 0.0% |

普通 12 源共同方向在全部 `12/12` 个 `seed × skill` 条件上优于单失败梯度，平均优势为
`+0.037998`。硬净化比普通均值平均低 `−0.012227`，仅 `1/12` 条件胜出。因此：

- H6 的方向性命题成立：一次失败产生的梯度通常可以迁移，但强度不足且仍有 18.1% 负响应；
- H8 成立：多条独立失败的共同方向显著更稳定、更强；
- “低 cosine 源应该直接删除”被否定。

逐 skill 结果揭示了 30% 门槛的非对称性：

| skill / 12 源均值 | 概率价值相对提升 | top-value 失败救回 |
|---|---:|---:|
| go | +16.30% | **+33.33 点** |
| open | +5.79% | +0.00 点 |
| close | **+35.27%** | +12.50 点 |

`close` 通过价值 30% 门槛，`go` 通过动作救回 30 点门槛，但没有一个 skill 同时通过两道门，
所以按提交规则所有 delta 都应回滚或只保留在实验性条件 bank，不能永久写入共享参数。

强度副作用同样明显。普通共同方向在同 skill 留出上的 top-value harm 为 0%，但如果无条件作用于
同任务异 skill 和完全无关状态，top harm 分别达到 41.7% 和 47.2%。这直接证明 H10 的解决方案
必须包含条件隔离，不能只做更大的全局参数更新。

## 12. H10 条件 delta bank × SEED 横评

使用 4 个固定 seen 梯度库，在相同 971 状态、FP32 Base、plain prompt、tokenizer、候选动作和
环境价值上比较。`oracle_skill` 表示已知当前执行 skill 的机制上界；`base_predicted_skill` 只根据
Base 第一选择动作路由，是不读取 expert/value 的部署下界。

| 路由 | split | 概率价值相对提升 | top-value 相对提升 | SEED 价值 | SEED top-value | 30% 通过 |
|---|---|---:|---:|---:|---:|---|
| Base 预测 skill | seen | +4.89% ± 0.58% | +23.38% ± 14.48% | +4.96% | +38.85% | 否 |
| Base 预测 skill | unseen | +3.15% ± 1.01% | −5.21% ± 14.94% | +4.63% | +19.05% | 否 |
| 已知 skill | seen | **+10.23% ± 0.58%** | **+57.01% ± 11.29%** | +4.96% | +38.85% | 价值否 / top 是 |
| 已知 skill | unseen | **+7.69% ± 1.30%** | +8.93% ± 12.96% | +4.63% | +19.05% | 否 |

已知 skill 路由将 seen/unseen 平均概率价值从 Base 的 `0.595442/0.569996` 提高到
`0.656354/0.613856`；SEED 为 `0.624960/0.596409`。因此条件隔离在概率价值上明显超过 SEED，
并把此前全局 300× delta 的 unseen `−0.04%～+1.12%` 提高到 `+7.69%`。

但这仍然不是闭环成功：

- 概率价值没有达到 30%；
- unseen top-value 提升低于 SEED且种子间不稳定；
- Base 预测路由在 seen 仅约等于 SEED 的概率价值，在 unseen 更弱且 top-value 为负；
- 当前 ALFWorld 路由上界使用记录 action skill，只能作为机制验证。

## 13. 最终判断

> **相似 skill 的失败价值梯度确实可以形成强、可迁移的共同参数方向；多失败共同方向稳定优于
> 单失败梯度，技能条件激活也确实大幅缓解了全局强写回的 unseen 退化，并在概率价值上超过
> SEED。可是当前方法仍未达到 30% 的综合价值提升，且真实可用的无 oracle 路由不稳定。因此，
> “梯度经验可以帮助自净化”成立，“它已经可以替代传统技能训练”不成立。**

下一轮不应继续盲目增加 300× 剂量。最直接的两个瓶颈是：

1. `open` 梯度共同方向本身弱，需要把经验粒度从 verb 细分为“动作 × 状态阶段 × 前置条件”；
2. Base 无法可靠调用 `close` 等强梯度记忆，需要使用执行器显式 skill id，或训练不读取 expert 的
   状态阶段 router。

只有当无 oracle 路由在 unseen 同时达到 30% 价值提升、30% 决策提升和不超过 2% 的保护集伤害，
才进入完整 episode 成功率实验。
